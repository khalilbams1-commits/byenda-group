Atelier de collaboration des agents. Crée un dossier, choisis les agents dans l'ordre, transmets le brief au premier, colle sa réponse, puis passe le relais au suivant. Les transmissions sont organisées ici ; l'exécution IA se fait dans Claude ou ChatGPT tant que les API ne sont pas connectées.

Comment les agents travaillent ensemble

1. Le premier agent reçoit le brief. 2. Tu colles sa réponse dans le dossier. 3. Le bouton « Préparer le relais » construit une nouvelle consigne avec le brief et le résultat précédent. 4. Tu l'envoies au prochain agent. 5. Tu peux terminer avec une synthèse de direction. Aucun résultat n'est inventé : chaque réponse doit être fournie par l'agent dans son outil.

Mode d'emploi commun des agents

Chaque agent doit : confirmer l'objectif, demander les informations manquantes, signaler ses hypothèses, livrer un résultat structuré, indiquer ce qui reste à valider et ne jamais prétendre avoir exécuté une action externe sans preuve.
